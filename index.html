Residuals (test)

    

  


  

    
Good for t-tests, chi-square, Mann-Whitney, ANOVA, Kruskal-Wallis.

    

      

        One-Sample T-Test
        

          
Use when: testing if one numeric column’s mean differs from a known value (e.g. “is average delivery time really 30 min?”).

          
H₀: μ = μ₀. Assumptions: ~normal data (or n ≥ 30). Read: p < 0.05 → the mean differs significantly; check the CI for practical meaning.

        

        

          

          

        

        
        

      

      

        Two-Sample T-Test (Independent)
        

          
Use when: comparing the average of a metric across two separate groups (A vs B, control vs treatment).

          
H₀: means are equal. Welch (default) doesn’t assume equal variances — usually safer. Non-normal? Use Mann-Whitney U instead.

        

        

          

          

          

          

        

        
        
        

      

      

        Paired T-Test
        

          
Use when: two measurements on the same rows (before/after, machine A vs B on the same units).

          
H₀: mean of the paired differences = 0. Rows missing either value are dropped pairwise.

        

        

          

          

        

        
        

      

      

        One-Way ANOVA
        

          
Use when: comparing a numeric column’s means across 3+ groups (e.g. spend by device).

          
H₀: all group means equal. Overall test — if significant, follow up pairwise with t-tests. Non-normal? Kruskal-Wallis.

        

        

          

          

        

        
        

      

      

        Chi-Square Test of Independence
        

          
Use when: proving whether counts of one category differ across another category (e.g. conversion rate by campaign group).

          
H₀: the two columns are independent. Assumption: expected counts ≥ 5 (we warn you). Cramér’s V shows association strength (0 none, 1 perfect).

        

        

          

          

        

        
        

      

      

        Mann-Whitney U (non-parametric)
        

          
Use when: comparing two groups on a skewed / ordinal / non-normal metric — tests whether one distribution tends to be larger, using ranks.

          
H₀: distributions are equal. Report medians alongside. Rank-biserial effect size: 0 = no tendency, ±1 = complete separation.

        

        

          

          

          

          

        

        
        

      

      

        Kruskal-Wallis (non-parametric ANOVA)
        

          
Use when: comparing 3+ groups on a non-normal metric — rank-based alternative to ANOVA.

          
H₀: all group distributions equal. ε² effect size: ~.01 small, ~.06 medium, > .14 large.

        

        

          

          

        

        
        

      

      

    

  


  

    

      
In-browser sentiment analysis (transformers.js + ONNX)

      
DistilBERT / Twitter RoBERTa run locally via WebAssembly — no server, no API key. Models download once (~27–50 MB) and are cached in IndexedDB for offline reuse. Rows are sampled (seed 42), capped at 100, and scored in small batches with live progress.

      
      
      

        

        

      

      
      
idle

      
Long texts are truncated to 1000 characters. Results are written back to df_master as sentiment_label and sentiment_score — usable in graphs, models and tests like any other column.
